# Lumen ops toolbox

This directory hosts operator-focused material (advanced flows, validator
bootstrap, monitoring, private networking).

Key docs:

- `become_validator.md` – guidance for turning a synced node into a validator.
- `stake_bootstrap.md` – notes for staking / delegation flows.
- `validator_specs.md` – recommended hardware / topology specs.

Most day-to-day operators only need the root-level `README.md` and `join.sh`.
